# Domain Docs

Before exploring, read the root `CONTEXT.md` and ADRs in `docs/adr/`
that apply to the work. If they do not exist, proceed silently.

This repository uses a single-context layout:

```
/
|- CONTEXT.md
|- docs/adr/
`- src/
```

Use glossary terminology from `CONTEXT.md` in issues, code proposals,
and tests. Explicitly flag any output that conflicts with an ADR.
